# Hash Table Implementation of the Dictionary/Map ADT

---

# Module Overview

1. Dictionary and Map ADTs: keys, values, operations, and storage options.
2. Hash Tables and Hash Functions: mapping keys to array locations.
3. Closed Hashing and Probing: collisions and storage within a table.
4. Open Hashing and Separate Chaining: linked entries, load factor, and rehashing.
5. Hash Table Implementation and ADT Review: implementation sketches and iteration.
6. Java Maps and Sets: applying the ADTs with java.util library classes.

---

# Module Summary

- Describe dictionary behavior independently of its implementation.
- Explain hashing and compare collision-resolution strategies.
- Relate load factor and resizing to operation costs.
- Apply Java Map and Set interfaces to key-value data.
