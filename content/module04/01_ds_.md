# What do each of those growth rates mean?
- O(1), Constant
- O(n), Linear
- O(n²), Quadratic
- O(log n), Logarithmic

---

# Constant

No matter what the situation, the runtime will not change.

---

# No growth

- Constant means no growth.
- O(1) remains the same whether there are 800 or 8 million items.

---

# Linear

- Runtime grows proportionally to the input size.
- Input is typically the number of stored elements.

---

# ArrayStack toString method

```java
public String toString() {
   StringBuilder output = new StringBuilder();
   for (int i = 0; i < count; i++) {
       output.append(stack[i] + ", ");
   }
   return output.toString();
}
```
