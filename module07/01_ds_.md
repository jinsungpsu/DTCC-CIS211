# Multiplication Method

Multiply by a constant, extract the fractional portion, and scale to the table size.

---

# Multiplication Method Example

```java
float A = 0.0123;
int tableSize = 100;

double hash1 = (key.toString().charAt(0)
              + key.toString().charAt(1)) * A;

double hash2 = hash1 % 1;
int index = (int)(hash1 * tableSize);
```

---

# Mid-Square Method

- Square the key
- Extract middle digits
- Use middle digits as the hash value

---

# Mid-Square Method Example

```java
int tableSize = 100;
int hash1 = 177;
hash1 *= hash1;
String hash2 = String.valueOf(hash1);
hash2 = hash2.substring(1, 4);
int index = Integer.parseInt(hash2) % 100;
```

# Rehashing

Resize and recompute indices to maintain efficiency.

---

# Process of Rehashing

1. Create larger table.
2. Recompute hashes.
3. Reinsert elements.
4. Update references.

---

# Load factor

The load factor measures how full a hash table is.

[Diagram illustrating load factor]

---

# Ideal load factor?

- Too high → more collisions.
- Too low → wasted memory.

---

# Rehash Thresholds

- Closed Hashing: > 0.5 or 0.75
- Open Hashing: can exceed 1.0
