# The “magic” of % (modulo operator)

```text
1 % 2 = 1
2 % 2 = 0
3 % 2 = 1
4 % 2 = 0
```

Result cycles through a range.

---

# any value % by any value…

```text
a % b
```

Result is always in the range:

```text
[0, b-1]
```

---

# % array.length

```text
any value % array.length
```

Produces values within array bounds and wraps around.
